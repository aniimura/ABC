## 何が起きたか(2026-09-07、実測)

本体が `sed -n '/## 1\./,/…/p'` で「原文の逐語」だけを取り出したため、
冒頭 8 行目の


を**切り落とした**。その結果、★**既に 3 形で埋まっている `Corollary 6.3` を

★**道具は正しく警告していた。消したのは人間側の絞り込みである。**

## なぜ索引の grep でも当たらなかったか

本体は `.cache/decl-index.txt` を `e_?0` などの**語**で引いたが、
実際の宣言名は `nat_card_quot_zero_dvd_of_ne` だった。
⇒ ★**[[mathlib-absent-by-wrong-name]] を本体自身が守っていなかった。**
語で 0 件でも「無い」と結論してはいけない。

**Why:** 道具の出力を絞る操作は、**自分が探している情報**は残すが
**自分が知らない情報**を落とす。警告はいつも後者である。

**How to apply:**

- ★`brief.mjs` は 2026-09-07 から**冒頭と末尾の両方**に同じ警告を出す。
  どちらか片方だけを読んでも当たるようにした（道具側の対策）。
