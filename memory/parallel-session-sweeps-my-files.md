`D:\Math_ABC3` は**複数の Claude セッションが同じワークツリーを共有する**。
2026-08-17 に事故が起きた——**別セッション(FrdI 担当)のコミット `fc53e84` が、
私が作業中だった `Found/GenEll/Conductor.lean` と
`Skeleton/GenEll/Section1.lean` を丸ごと巻き込んだ**。

★内容は失われないが、**私のコミットメッセージが対応する内容に付かない**。
本プロジェクトではコミットメッセージが**測定と判断の記録そのもの**なので、これは実害である。
(実際、その 2 ファイルの「`Proposition 1.6` の非アルキメデス側」という測定は、
別セッションの「`Ψ` の well-defined 性」というメッセージの下に入ってしまった。)

**Why:** 自分が `git add <path>` でパスを限定しても、**相手が `-A` / `-a` を使えば無意味**である。
守れるのは「相手のコミットが起きる前に自分がコミットを終えていること」だけ。

**How to apply:**
- ★**1 ファイルが `lake env lean` を通ったら、その場でコミットする。**
  複数ファイルを溜めてからまとめてコミットしない。
- ★`git add -p` は**使わない**——対話モードに入って 10 分でタイムアウトした(同日)。
- コミット直前に `git log --oneline -3` を見て、相手のコミットが挟まっていないか確かめる。
- 巻き込まれてしまったら、**歴史を書き換えない**(相手のコミットは相手のもの)。
  代わりに次のコミットのメッセージに「本体は `<sha>` にある」と書いて対応づける。
- 逆に**自分が `-A` を使わない**。相手の作業中ファイルを拾うと同じ迷惑になる。
