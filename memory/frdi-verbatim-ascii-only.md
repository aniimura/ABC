`tools/check.mjs` の逐語照合は **PDF の layout 抽出**と突き合わせるが、
`ResearchPaper/0_Source/*.txt` の抽出とは**字が違う**文字がある。
確認済みで落ちるもの: `▷` `′` `⪯` `≼` `̸=` `↪` `ϵ` `±1`(layout は `±` だけ)、
`𝔽_Φ`→`FΦ`。★**txt から splice しても落ちる**(txt と layout で codepoint が違う)。

**Why:** 2026-08-16〜17 だけで 6 回この事故を起こした。手で打つのはもちろん、
txt から機械的に splice しても `▷` を含む行は通らない。

**How to apply:** 引用は必ず **ASCII だけの連続断片**に切る。手順:
1. 該当ページのテキストを取り出す
2. 目印の語から始めて、**最初の非 ASCII 文字の直前で切る**
3. 25 文字以上あることを確認し、正規化(空白除去)して同ページに含まれることを assert
4. その文字列を Lean ファイルへ書き込む

★連続する `>` 行は**1 ブロック**として原典の連続行と照合されるので、
別々の引用にしたいときは `原文 (FrdI p.NN):` の見出しで分ける。
★`原文 (FrdI p.NN):` のページ番号は**物理ページ**(`===== [page N] =====`)であり、
語の初出ページとは限らない(§0 の skeleton は p.11 ではなく p.15 だった)。
