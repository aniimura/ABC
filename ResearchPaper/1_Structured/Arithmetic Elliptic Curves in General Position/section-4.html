Lemma 4.1. (The Existence of Primes of Prescribed Size) Write
ℝ′_{>0} ⊆ ℝ_{>0} を素数の集合の補集合、 θ(x) ≝ Σ_{p<x} log(p)(和は素数 p < x について)とする。 M を正整数、ϵ, x_ϵ, C_ϵ ∈ ℝ_{>0} を 0 < ϵ < 1/4、ϵ·x_ϵ > C_ϵ かつ次を満たすものとする:
(i) 全ての x ∈ ℝ′_{>0} で (5/4)·x + C_ϵ > θ(x); かつ x ≥ x_ϵ なる全ての x ∈ ℝ′_{>0} で θ(x) > (1−ϵ)x;
(ii) x ≥ x_ϵ なる全ての x ∈ ℝ_{>0} で M·log(x) ≤ ϵ·x。
また有限素数集合 A に対し x_A ≝ Σ_{p∈A} log(p) と書く。
このとき任意の非負 h ∈ ℝ と x_A > x_ϵ なる任意の有限素数集合 A に対し、 M 個の相異なる素数 p_1,…,p_M が存在して p_j ∉ A かつ h ≤ p_j ≤ (1+6ϵ)·x_A + 8h(j = 1,…,M)。

Lemma 4.2. (Some Elementary Estimates) Let n be a positive integer;
n を正整数、p_1,…,p_n を素数、h_1,…,h_n を正整数とし h ≝ Σ_{j=1}^n h_j·log(p_j) とすると:
Σ_{j=1}^n log(p_j) ≤ h、
Σ_{j=1}^n log(h_j) ≤ Σ_{j=1}^n log(h_j + 1) ≤ 3h/2。

★★純粋に初等的であり、今すぐ Found/ に実装できる。 原文の証明は 2 行——第 1・第 2 不等式は直ちに従い、第 3 不等式は 「任意の正整数 H について log(H+1) ≤ (3H/2)·log(2)」という 容易に確かめられる事実から従う(p.21 目視確認)。

★p_j ≥ 2 より log(p_j) ≥ log 2 なので h ≥ log(2)·Σ h_j、したがって Σ log(h_j+1) ≤ (3/2)·log(2)·Σ h_j ≤ (3/2)·h。★この筋は完全に追える。

Corollary 4.3. (Full Galois Actions for Degenerating Elliptic Curves)
ℚ̄ を ℚ の代数閉包、ϵ ∈ ℝ_{>0} とすると、 定数 C ∈ ℝ_{>0} と Galois-finite な部分集合 Exc ⊆ M_ell(ℚ̄) が存在して次を満たす:
E_L を数体 L ⊆ ℚ̄ 上の楕円曲線で、L が点 [E_L] ∈ M_ell(ℚ̄) の 最小定義体であり [E_L] ∉ Exc とし、S を有限素数集合、 E_L は潜在的乗法還元の素点を 1 つ以上持つとする。 d ≝ [L:ℚ]、x_S ≝ Σ_{p∈S} log(p) と書くと、 S に属さない素数 l_∘, l_• が存在して:
(a) l_∘, l_• は E_L の潜在的乗法還元の素点および局所高さと素。 さらに l_• は L で分岐する ℚ の素数および ℚ の素数の L での分岐指数と素。
(b) Gal(ℚ̄/L) → GL₂(ℤ_{l_∘}) の像は SL₂(ℤ_{l_∘}) を含み、 Gal(ℚ̄/L) → GL₂(ℤ_{l_•}) は全射。
(c) l_∘ ≤ 23040·900d·ht^Falt([E_L]) + 2x_S + C·d^{1+ϵ}、 l_• ≤ 23040·900d·ht^Falt([E_L]) + 6d·log-diff_{M̄_ell}([E_L]) + 2x_S + C·d^{1+ϵ}。

★証明は Theorem 3.8 の条件 (a) を使う。 途中で「l が L で不分岐なら『像が SL₂ を含む』⇔『全射』」を ℚ(ζ_{l^∞})/ℚ が l で完全分岐、ゆえに L/ℚ と線型無関連から出している。 ★23040·900 = 23040·(2·3·12 + 8·100 ≤ 900) という係数の由来も p.23 に書かれている。

Corollary 4.4. (Full Galois Actions for Compactly Bounded Subsets)
ℚ̄ を ℚ の代数閉包、K_V ⊆ M_ell(ℚ̄) を compactly bounded subset とすると、 定数 C ∈ ℝ_{>0} と Galois-finite な部分集合 Exc ⊆ M_ell(ℚ̄) が存在して次を満たす:
E_L を数体 L ⊆ ℚ̄ 上の楕円曲線で、L が [E_L] の最小定義体、 [E_L] ∈ K_V かつ [E_L] ∉ Exc、S を有限素数集合とする。 d ≝ [L:ℚ]、x_S ≝ Σ_{p∈S} log(p) と書くと、 S に属さない素数 l_∘, l_• が存在して (a)(b) は Corollary 4.3 と同一、
