[Stacks] Lemma 29.42.7（tag 01W6）

The Stacks Project、Chapter 29 Morphisms of Schemes、§29.42 Proper morphisms。 物理 p.2520。150 dpi 目視確認 2026-08-27。

(2) If X is proper over S, then the morphism X → Y is proper. In particular, in both cases the image of X in Y is closed.

可換三角形 X → Y → S（X → S が合成）で Y が S 上分離的なとき:

  • (1) X → S が普遍閉なら X → Y も普遍閉。
  • (2) X が S 上固有なら X → Y も固有。
  • いずれの場合も X の Y における像は閉。

★原文の証明は X → X ×S Y → Y と分解する。 第 1 射はグラフだから閉埋め込み（Schemes, Lemma 26.21.10）、 第 2 射は普遍閉（resp. 固有）の底変換（Lemma 29.42.5）。

★★★これが [GenEll] Proposition 1.4, (iv) の「埋め込み」の段の後半である ——Xℚ が ℚ 上固有で ℙⁿℚ が ℚ 上分離的だから、 i : Xℚ → ℙⁿℚ（Lemma 29.40.4 が与える immersion）は 閉埋め込みになる。

★★★★この段は mathlib で完全に書ける（2026-08-27 実測）。 IsProper.of_comp（Mathlib/AlgebraicGeometry/Morphisms/Proper.lean）が 本補題 (2) そのものであり、UniversallyClosed.of_comp_of_isSeparated が (1) である。 ★あとは IsImmersion ＋ 普遍閉 ⟹ IsClosedImmersion を IsClosedImmersion.of_isPreimmersion ＋ Scheme.Hom.isClosedMap で結ぶだけ。 ★★Found/Stacks/ProperImmersion.lean に sorry 無しで置いた。
