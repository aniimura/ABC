(i) Suppose that the codomain of any arrow of C whose domain is equal to A is
A から出る射の終域がすべて isotropic なら、 A を始域とする射は co-angular。 さらに「φ が Frobenius 型 ⟺ isometric な base-isomorphism」。

★これだけが pre-Frobenioid のまま成り立つ。 原文は「follows formally from the definitions」としか書かないが、 実際に書いてみると 1 行だった —— co-angular の条件に現れる β は「A から出る射 γ の終域」から出る isometric pre-step なので、 isotropy から直ちに同型。★「formally」は何も隠していなかった。

(ii) Suppose that C is a Frobenioid. Then φ is a pull-back morphism if
φ が pull-back morphism ⟺ LB-invertible な linear 射 （= co-angular な linear isometry）。

順方向は Definition 1.3, (iv), (b) そのもの。 逆方向は Definition 1.3, (iv), (a) の分解を取り、linear 性から γ が同型、 isometry 性から γ ≫ β が isometric pre-step、co-angular 性からそれが同型、 よって φ は pull-back morphism。

(iii) Suppose that C is a Frobenioid. Then every LB-invertible pre-step
LB-invertible な pre-step は同型。

★原文は2つの道を示す —— Definition 1.3, (v), (b) の分解の一意性、 または Definition 1.3, (ii) の Frobenius 型射の本質的一意性。 Lean 側は後者を採った。 ★前者の道は、自己監査で足した preStepFactorUniq（一意性節）が無ければ通らなかった —— 緩い転写が下流で効かなくなる実例である。

(iv) Suppose that C is a Frobenioid. Then a morphism φ of C is co-angular
φ が co-angular ⟺ Definition 1.3, (iv), (a) の分解 φ = α ∘ β ∘ γ における pre-step β が co-angular。

★逆方向が本命で、𝒟 が totally epimorphic であることを使う —— β の3分解に対し、Base β が同型であることから各因子の Base も同型 （原文 p.16 の「in passing」の観察 = Lean 側の isIso_of_isIso_comp）。

(v) Suppose that C is a Frobenioid. Then a morphism φ of C is LB-invertible
φ が LB-invertible ⟺ φ = α ∘ β（α は pull-back morphism、 β は Frobenius 型射）の形。

★(ii)(iii)(iv) をすべて使うので、順序は最後。 逆方向で β が isometric であることを出すのに、 Φ.map の単射性（Definition 1.1, (ii), (a) の characteristically injective）が効く。

★負の対照

(i) の isotropy 仮定が効いていることを実物で示した。 𝒞 = Vee、𝒞 → 𝔽_Φ を定数関手に取ると、 Base はつねに 𝟙、Div はつねに 0、deg_Fr はつねに 1 になり、 Vee のすべての射が isometric pre-step になる。 すると left は isotropic でなく、left ⟶ top は co-angular でない。

★𝔽_Φ とその広い部分圏ではどの対象も isotropic である （isometric pre-step は (b, 0, 1) で b が同型、したがって既に同型）ので、 定数関手に取り替えることが必要だった。
