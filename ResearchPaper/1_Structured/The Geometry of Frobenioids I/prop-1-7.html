tries, base-isomorphisms, base-FSM-morphisms, pull-back morphisms,
linear morphisms, pre-steps, co-angular morphisms, LB-invertible mor-
9 クラスが合成で閉じる。

★9 クラスのうち 5 つは既に持っていた (IsIsometric.comp / isBaseIsomorphism_comp / IsPullBack.comp / IsLinear.comp / IsPreStep.comp)。新規は 4 つで、 うち base-FSM は §0 の IsFSMMorphism.comp を Base に沿って運ぶだけ、 残り 3 つは Definition 1.3, (iii), (a)(co-angular の合成)から組み立てるだけ。 ★(i) は本当に「immediate」だった。

★負の対照: 原文の列挙に無い step(同型でない pre-step)は 実際には閉じる(列挙は「閉じるもの全部」ではない)。 一方 prime-Frobenius morphism は 閉じない —— 模型 wP で次数 2 の Frobenius 型射を合成すると次数 4 になる。 原文が prime-Frobenius を外しているのは正しく、外した理由は「素数」の部分にある。

(ii) A morphism of C is a pull-back morphism if and only if it is minimal-
adjoint to the base-isomorphisms of C. A morphism of C is a base-isomorphism
if and only if it is minimal-coadjoint to the pull-back morphisms of C; alter-
pull-back ⟺ base-iso に minimal-adjoint。base-iso ⟺ pull-back に minimal-coadjoint。 さらに base-iso ⟺「Frobenius 型 ≫ pre-step」と書ける。

★★原文より短い道が見つかった。 原文は必要性を 「the essential uniqueness of this factorization」で説明するが、 分解の一意性は要らない —— γ := 𝟙(または α := 𝟙)に取って co-angularity をそのまま当てるだけで出る (Lean 側 isIso_of_isCoAngular_left / _right)。 使うのは Definition 1.3, (iv), (a) の分解の存在だけである。

(iii) A morphism of C is of Frobenius type if and only if it is minimal-
coadjoint to the linear morphisms of C. A morphism of C is linear if and only if
it is minimal-adjoint to the morphisms of Frobenius type of C; alternatively,
a morphism of C is linear if and only if it is may be written as a composite α◦β,
where α is a pull-back morphism, and β is a pre-step.
Frobenius 型 ⟺ linear に minimal-coadjoint。linear ⟺ Frobenius 型に minimal-adjoint。 さらに linear ⟺「pre-step ≫ pull-back」と書ける。

★linear の必要性について、原文は 「the well-known structure of the multiplicative monoid N≥1 and the essential uniqueness of morphisms of Frobenius type of a given Frobenius degree」を挙げるが、 Proposition 1.4, (iii)(LB-invertible な pre-step は同型)だけで済む。 ★ℕ≥1 の構造(単元が 1 だけ)を実際に使うのは (v) の linear のほうである。

(iv) A pre-step of C is co-angular if and only if it is mid-adjoint [cf. §0] to
the isometric pre-steps.
pre-step については、co-angular と「isometric pre-step に mid-adjoint」が一致する。

★中身は ⇒ の側である。co-angular の定義には 「α が linear」「α か γ が base-iso」という余分な仮定が付いているが、 φ が pre-step ならこの 2 つは (v) から自動で従う。 ★原文が「cf. the argument applied in the proof of Proposition 1.4, (iv)!」と 感嘆符つきで指す議論はこれである。

(v) If a composite morphism φ = α◦β of C is a(n) isomorphism (respectively,
base-isomorphism; linear morphism; pre-step; isometry; co-angular pre-
step; co-angular linear morphism; pull-back morphism), then so are α, β.
If, moreover, the domain of φ is isotropic, then a similar statement holds for
morphisms of Frobenius type.
合成が 8 クラスのいずれかに属せば、両因子も属する。始域が isotropic なら Frobenius 型についても同じ。

★使う入力が条ごとに違うのが要点: isomorphism は 𝒞 が totally epimorphic、 base-isomorphism は 𝒟 が totally epimorphic、 linear は ℕ≥1 の単元が 1 だけ、 isometry は Φ が sharp ＋ Definition 1.1, (ii), (a) の単射性。 ★isometry の段だけが Φ の sharp 性を使う —— Proposition 1.5 が pre-divisorial でよかったのに 1.7 が divisorial を仮定する理由がここにある。

★co-angular linear の段が原文でいちばん長い(1 段落まるごと)。 α, β をそれぞれ「isometric pre-step ≫ co-angular linear」に分解し、 真ん中に現れる β₁ ≫ α₂ をもう一度同じ形に分解して、 φ の co-angularity を 2 回当てる。 ★ここは短くならなかった —— (ii)(iii) で効いた「𝟙 を置く技」が使えず、 原文の段取りをそのまま辿る必要があった。
