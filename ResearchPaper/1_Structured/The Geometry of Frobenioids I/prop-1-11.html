(Pull-back and Linear Morphisms) Let Φ be a divi-
sorial monoid on a connected, totally epimorphic category D; C →FΦ a Frobe-
仮定は Proposition 1.10 と同じ。追加の仮定は各条が個別に置く。
(i) Suppose further that C is of Aut-ample and base-trivial type. Then the
natural projection functor Cpl-bk →D is full.
𝒞 が Aut-ample かつ base-trivial 型なら、 𝒞pl-bk → 𝒟 は full。

★2 つの型が両方要る：base-trivial が対象の側を、 Aut-ample が射の側を供給するはず。★着手前の見立てであり、 実装で確かめる。

(ii) Suppose further that C is of unit-trivial type. Then the natural projection
functor Cpl-bk →D is faithful.
unit-trivial 型なら同じ関手が faithful。

★(i) と (ii) で仮定が違うのが目を引く —— full と faithful が別々の型から来ている。 ★圏同値の 3 成分が別々の仮定に対応するという、我々が Proposition 1.6 で何度も見た形の再来である。

(iii) Let φ : B →A be a pull-back morphism that projects to a morphism
such that Base(α) ◦φD = φD ◦βD, there exists a unique β ∈EndC(B) such that
pull-back φ : B ⟶ A と、底で四角形を可換にする α ∈ End(A)、β_𝒟 ∈ End(B_𝒟) があれば、 それを持ち上げる β ∈ End(B) が一意に存在する。

★これは plBkOverFunctor の圏同値の言い換えに近い。 Definition 1.3, (i), (c) は (𝒞pl-bk)A → 𝒟A_𝒟 が圏同値と言うが、 ★(iii) はそれを「自己射の持ち上げ」として述べ直したものと読める。

(iv) Every co-angular linear morphism φ : B →A determines an injection
which is uniquely determined by the condition that O▷(A) ∋α →β ∈O▷(B)
co-angular で linear な射 φ : B ⟶ A は、 モノイドの単射 𝒪▷(A) ↪ 𝒪▷(B) を定める。 条件は α ↦ β が α ∘ φ = φ ∘ β を満たすこと。

★★逐語の注意（事故 #5 の再確認）： PDF は 𝒪▷(A) ↪ 𝒪▷(B)（単射の矢印）だが、 pdftotext は O▷(A) →O▷(B) と普通の矢印に変える。 ★400 dpi 目視で確認した。 ★これは事故 #5 で最初に記録した文字であり、別の場所で同じ変異が起きている。 散文に「an injection」とあるので意味は復元できるが、 ★矢印だけを見ると単射性が消える。

★Proposition 1.10, (iii) の moreover で我々は 𝒪▷(A) の perfect 性を扱った。★(iv) は同じ対象の 別の側面（射に沿った単射）である。

(v) The equivalences of categories of Definition 1.3, (iii), (d), are “functorial”
if and only if ψ is.
Definition 1.3, (iii), (d) の圏同値が関手的であること。 𝒞lin の射 φ と co-angular pre-step α、β が Div の条件を満たすとき、一意な ψ が存在し、 さらに φ が pull-back ⟺ ψ が pull-back。

★★これは我々が Proposition 1.10 で初めて消費した圏同値の 「次の使い方」である。 1.10 では**1 点で**使った（因子分解と元の実現）が、 ★(v) は関手全体としての振る舞いを問う。

★不足している道具：𝒞lin（linear 射のなす広い部分圏）。 IsLinear.comp は実装済みなので WideSubcategory で作れるはず。

(vi) A pull-back morphism φ ∈Arr(C) is an FSM-morphism (respectively,
fiberwise-surjective morphism; monomorphism; irreducible morphism) if
and only if Base(φ) ∈Arr(D) is.
pull-back 射については、4 つの性質が底と完全に対応する （FSM / fiberwise-surjective / monomorphism / irreducible）。

★★irreducible はこのセッションで足した語彙である （Proposition 1.10, (iv) のために §0 p.17 から写した）。 ★1 つの項目のために足した語彙が、次の項目で再び要る —— 語彙の投資が回収される形。

★4 つとも iffである。Proposition 1.10, (i) の 「7 タイプ」が場合によって独立でなかったのと違い、 ★ここは 4 つが別々の性質である（FSM と mono は無関係、 irreducible は分解の話）。★着手前の見立て。

(vii) Let φ : A →B be a co-angular pre-step; ϵ : C →B a morphism. Then
co-angular pre-step φ : A ⟶ B と任意の射 ϵ : C ⟶ B に対し、 co-angular pre-step γ : D ⟶ C と α : D ⟶ A が ϵ ∘ γ = φ ∘ α を満たす。とくに co-angular pre-step は FSM 射。

★「In particular」が付いている —— 我々は Proposition 1.10, (iv) でも「In particular」を開いた。 ★あちらは無限性の主張だったが、ここは定義の直接の帰結に見える。 IsFSMMorphism の定義と突き合わせて確かめる。
