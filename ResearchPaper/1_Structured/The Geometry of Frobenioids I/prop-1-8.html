★証明は 2 段落。着手前の測定で私は「3段落」と言ったが、 目視すると (iii) は第2段落の最後の1文である。

★★Definition 1.3, (iii), (d) の初使用

我々は Definition 1.3, (iii), (d) の 2 本の圏同値を Frobenioid の フィールドとして持っていたが、下流で一度も使っていなかった。 (iii) がその初使用である。

★結果: 使えた。 転写は正しかった。ただし 実際に効くのは「充満性」と「本質的全射性」の 2 つだけで、 忠実性は使わない。原文は「the equivalences of categories」と一括で言う。

(i) If the natural projection functor C →D is full, then every pre-step of
C is a linear End-equivalence. If D is of Aut-type [cf. §0], then every linear
End-equivalence of C is a pre-step.
投影関手が full なら pre-step は linear End-equivalence。 𝒟 が of Aut-type なら逆。

★前半は本当に formally —— 2 行。 Base φ の逆射を fullness で 𝒞 へ持ち上げるだけ。

★後半も formally だが、補題を1つ要した —— 「f ≫ g と g ≫ f がともに同型なら f は同型」。 mathlib の isIso_of_mono_of_isSplitEpi を経由して書いた。 原文は「it follows formally that φ is a base-isomorphism」としか書かない。

(ii) Suppose further that C is of metrically trivial and Aut-ample type.
Then a morphism of C is a co-angular pre-step if and only if it is abstractly
equivalent [cf. §0] to a base-identity pre-step endomorphism of C.
co-angular pre-step ⟺ base-identity pre-step 自己射に abstractly equivalent。

★★2つの仮定が別々の役割を持つと特定できた: metrically trivial は B ≅ A を与えて φ を自己射に変える、 Aut-ample は Base を打ち消す自己同型を与えてbase-identity にする。 片方だけでは届かない。

★★逆向きは追加仮定を一切使わない。 Definition 1.3, (iii), (b) を 𝟙 に当てると すべての自己射が co-angular になり、あとは「同型は co-angular pre-step」だけ。 ★原文は「follows formally」と一括で書き、この非対称性を述べていない。

(iii) An object A ∈Ob(C) is non-group-like if and only if there exists a
co-angular step A →B; alternatively, an object A ∈Ob(C) is non-group-like
if and only if there exists a co-angular step B →A. Also, if A, B ∈Ob(C) are
base-isomorphic objects, then A is group-like if and only if B is.
non-group-like ⟺ 出る co-angular step がある ⟺ 入る co-angular step がある。 base-isomorphic なら group-like 性が一致。

★★Definition 1.3, (iii), (d) をどう使ったか: ⟸ は充満性(Div φ が可逆なら MLe (Div φ) 0 なので Z ⟶ Z₀ が持ち上がり、φ ≫ (その射) = 𝟙 から φ が同型)。 ⟹ は本質的全射性(可逆でない d ∈ Φ(A) に対応する co-angular pre-step を取る)。忠実性は使わない。

★第3主張(base-isomorphic なら group-like 性が一致)は 圏同値を使わない —— Φ の関手性だけで出る。 原文は3主張を一括で「the equivalences of categories of Definition 1.3, (iii), (d)」に 帰しているが、3番目はそれに依らない。

★負の対照(両側): 𝔽_ℕ(= wP)では wTop は group-like でなく、co-angular step wDiv1 が実在する(両側成立)。 𝔽_ℤ ではすべての対象が group-like で、step が1つも無い (ℤ では零因子がつねに可逆なので pre-step はすべて同型)(両側不成立)。 ℤ は pre-divisorial なので 𝔽_ℤ は Proposition 1.5 により 本当に Frobenioid である。
