[FrdI] §0 — モノイドと圏の語彙

物理 p.11–p.16。400 dpi 目視確認 2026-08-15。 Definition 1.1 と Definition 1.2 が引く語をここに集める。

モノイドの語彙(p.11–p.12)

M ± = 0; we shall say that M is integral if the natural map M →M gp is injective;
sharp = 可逆元が 0 だけ(M± = 0)。 integral = 群化への自然写像 M → Mgp が単射。

★M ± は原文では上付きの M±。 pdftotext が上付きを空白区切りの別トークンにするため M ± と出る。 「M と ±」に読め、単項演算の記号と紛れる。

we shall say that M is saturated if every a ∈M gp for which n · a lies in the image
saturated = n · a(n ≥ 1)が M の像に入るような a ∈ Mgp は、それ自身 M の像に入る。

★これは mathlib の AddSubmonoid.NSMulSaturated と同じ条件である。 Lean 側の frdI_saturated_iff で同値を証明した。

characteristic type if the fibers of the natural map M →M char are torsors over M ±.
of characteristic type = M → Mchar のファイバーが M± 上のトーサー(単純推移的)。

★Mchar = M/M± は商モノイドである。 Lean 側では charCon : AddCon M を作って MChar M として構成した。

injective if φ is injective, and, moreover, the morphism M char
characteristically injective = φ が単射で、かつ 誘導される M1char → M2char も単射。

★2つ要求するのが要点である。単射だけでは足りないことは Lean 側の not_isCharacteristicallyInjective_natCast(ℕ ↪ ℤ)で示した。 これは Definition 1.1, (ii), (a) が引く語。

Denote by Primary(M) the set of primary
primary = 0 ≠ a であって、0 ≠ b ⪯ a なる任意の b に対し a ⪯ b が成り立つもの。Definition 1.2, (iii) の primary pre-step が引く。

★primary の定義文そのものは逐語照合に掛けていない。 ≠ が pdftotext では合成文字(スラッシュ + 等号)になり、照合器が拾えないためである。 書き換えずに、照合できない事実として記す。

圏の語彙(p.14–p.16)

monomorphism will be referred to as an FSM-morphism. One verifies immediately
FSM-morphism = fiberwise-surjective な monomorphism。 fiberwise-surjective は「任意の γ : C → A に対し β ∘ δB = γ ∘ δC となる δB : D → B、 δC : D → C が存在する」。

★★この定義は始対象を持つ圏で退化する—— D に始対象を取ると条件が空虚に満たされ、すべての射が fiberwise-surjective になる。Lean 側の isFiberwiseSurjective_of_initial で証明した。 ★原文は D に条件を付けていない。防いでいるのは totally epimorphic の側で、 subsingleton_hom_of_isTotallyEpimorphic_of_initial により 「totally epimorphic + 始対象 ⟹ 前順序」となる。 原文はこの導出を明示していない。

(respectively, almost totally) epimorphic if every morphism in C whose domain is
totally epimorphic = すべての射が epimorphism。 原文は括弧で almost totally と二重に述べるが、totally の側は domain も codomain も任意なので条件はこれに尽きる。
as a connected component of C. In particular, we shall say that C is connected if
★§0 は圏についての connected を定義している—— グラフ G(C)(対象を頂点、射を辺とする)が連結であること。

★これは始対象を排除しない。始対象を持つ圏はつねにグラフとして連結である。 したがって Definition 1.1, (iv) の「connected, totally epimorphic categories」の connected では上記の退化を防げない。防いでいるのは totally epimorphic の側である(上の frdi-s0-fsm 参照)。

We observe in passing that if C is a totally epimorphic category, and α ◦β
totally epimorphic な圏では、α ∘ β が同型なら α と β も同型。

★原文は「in passing」と述べるだけで証明を置かない。 Lean 側の isIso_of_isIso_comp で実際に証明した。
