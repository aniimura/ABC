§4 見出し & §4.1 冒頭(L の固定) — 物理 p.6

4. Lubin-Tate extensions and Artin maps 4.1. Lubin-Tate extensions. Here we fix a complete unramified extension L of K.
§4 全体を通じての約束: L は K の「完備不分岐拡大」(Definition 2.4)。 ★ここが §4 を読むときの最初の落とし穴——Definition 2.4 は 「L = E(有限分岐拡大 E の完備化)を K の完備拡大と呼ぶ。 E/K が有限なら L = E」と明記しているので、 有限不分岐拡大 Kn それ自身も「完備不分岐拡大」である。 つまり L は K = Kur のような無限次のものだけを指すのではない。 Definition 4.10 の「with L/K finite」はこの範囲内での制限であって、 §4.1 との矛盾ではない(下の「確定」欄を見よ)。
π は L の素元、ϕ は算術 Frobenius を L の K-自己同型へ延長したもの(§3.2)。

Definition 4.1(Lubin-Tate 拡大 Lmf と分点 µf,m) — 物理 p.6

Definition 4.1. Let f ∈ OL[X] be a monic polynomial satisfying (3.2.1) for a uniformizer π of L. For m ≥ 1, let Lmf be the splitting field of fm ∈ OL[X] (Definition 3.9) over L, and let µf,m := {α ∈ Lmf | fm(α) = 0}.
Lubin-Tate 拡大の定義。fm = fϕm−1 ◦ … ◦ fϕ ◦ f (Definition 3.9)の分解体を Lmf と書き、 その根の集合を µf,m と書く。 (3.2.1) は f(X) ≡ πX (mod deg 2) かつ f(X) ≡ Xq (mod p) という Lubin-Tate 条件(Lemma 3.4)。
★f は多項式(§3 の f は形式的冪級数 OL[[X]] だった)。 §4 では分解体を取りたいので OL[X] に制限される ——この制限は §4 の冒頭で静かに入る。

Example 4.2(円分の場合) — 物理 p.6

Example 4.2. In Example 3.6, we have fm(X) = [pm]f(X) = (1 + X)pm − 1, µf,m = {ζ − 1 | ζ ∈ µpm} and Lmf = L(µpm) for all m ≥ 0.
K = Qp、π = p、f = (1+X)p − 1 のとき Lubin-Tate 拡大は円分拡大に一致する。この 1 行が「Lubin-Tate 理論は円分体論の一般化である」の内容。

Lemma 4.3(見出し & (i)。(ii) は次の項目) — 物理 p.6

Lemma 4.3. Let m ≥ 1 and f ∈ OL[X] as above, and set L′ := Lmf and [·] := [·]f. (i) The extension L′/L is separable and µf,m ⊂ pL′. (In particular, we can substitute the elements of µf,m into power series over OL (see Appendix I).)
(i) は「分点は極大イデアルの中にある」——冪級数を代入できる(収束する)ための前提。 分離性は char K = 0 なら自動、一般には Appendix II の Proposition II.1 に外注される。
★Lemma 4.3 は物理 p.6 と p.7 にまたがる。 逐語照合は 1 ページ単位なので、 本ファイルは見出し+(i) を lemma-4-3(p.6)、(ii) を lemma-4-3-ii(p.7)に分けている—— 原典で 1 つの Lemma を 2 つの構造単位に割ったことをここに明記する。

Lemma 4.3(ii)(分点の特徴づけ) — 物理 p.7

(ii) For x ∈ K× with v(x) = m and α ∈ pLsep : α ∈ µf,m ⇐⇒ [x](α) = 0 ⇐⇒ [a](α) = 0 (∀a ∈ pm).
★Proposition 6.14 が直接消費する 3 つのうちの 1 つ(§6 の依存表は初版で 「Prop 4.3(ii)」と書いていたが、指しているのはこの Lemma 4.3(ii) である ——原典で 4.3 は Proposition ではなく Lemma。下の「§6 への出口」を見よ)。

Proposition 4.4(µf,m の O-加群構造・完全分岐性・ρf,m) — 物理 p.7

Proposition 4.4. Let m ≥ 1 and f ∈ OL[X] as above, with the linear coefficient π. (i) The set µf,m is an O-module by +Ff and [·]f. For any α ∈ µ×f,m := µf,m \ µf,m−1, the following is an isomorphism of O-modules: O/pm ∋ a mod pm ⟼ [a]f(α) ∈ µf,m. (ii) If α ∈ µ×f,m, then Lmf = L(α), NLmf/L(−α) = πϕm−1 and α is a uniformizer of Lmf. The Lmf/L is totally ramified Galois extension of degree |µ×f,m| = qm−1(q − 1). (iii) We have canonical isomorphisms of abelian groups: ρf,m : Gal(Lmf/L) ≅⟶ AutO(µf,m) ≅⟶ (O/pm)×. (α ↦ [u]f(α), ∀α ∈ µf,m) ⟼ u mod pm
★§4 の中心。3 つの主張が別々に §6 で消費される:
  • (i) O/pm ≅ µf,m (a ↦ [a]f(α))——分点が階数 1 の自由 O/pm-加群。
  • ★(ii) α ∈ µ×f,m が Lmf の素元であり、Lmf/L が 完全分岐ガロアで次数 qm−1(q−1)。 ★Proposition 6.14 が最初に使うのはこれ——素元だから i(σ) = v(σ(α) − α) と書ける(Definition 6.1 の 「π の取り方に依らない」を具体的な α で使う)。
  • ★(iii) ρf,m : Gal(Lmf/L) ≅ (O/pm)×。 ★Proposition 6.14 が 2 番目に使う——σ を u mod pm に翻訳して σ(α) = [u]f(α) と書き直す。
★記法の脱落: ⟼(\longmapsto)は pdftotext に −→ としか出ず、↦(\mapsto)は → としか出ない ——縦棒(↦ の起点)が消える。 ≅ は ∼ と = の 2 トークンに割れる(§6 と同じ)。

§4.2 冒頭(Artin 写像の記法: ( )(i) と πj) — 物理 p.7

4.2. Artin map. In this subsection we use the notation ( )(i) := ( )ϕi and µ(i)f,m := µf(i),m for all i ∈ Z. We extend Definition 3.9 to define πj ∈ L× for all j ∈ Z by requiring πj+j′ = π(j)j′πj for all j, j′ ∈ Z, i.e. πj := (π−1−j)(j) for j < 0. Then vL(πj) = j for all j ∈ Z.
§4.2 だけで通用する 2 つの略記: (a) ( )(i) は Frobenius の i 乗を掛けること、 (b) πj(Definition 3.9 の πm = ∏t=0m−1πϕt)を 負の j へ延長したもの。vL(πj) = j なので πj は「付値 j の標準的な元」として働く。
Lean 化の観点: (b) は π• : Z → L× が 1-コサイクル(πj+j′ = πj′(j)πj) であることの言い換えであり、これ自体が独立の節点になる。

Lemma 4.5(Θ の元と πj の関係) — 物理 p.7

Lemma 4.5. If θ ∈ ΘLπ,π′, then θ(j)/θ = π′j/πj for all j ∈ Z. Also, πj ∈ ΘLπ,π(j).
Definition 3.3 の ΘLπ,π′ = {θ | θϕ/θ = π′/π} が j = 1 の場合であり、本補題はそれを全ての j へ持ち上げる(両方向の帰納法)。 第 2 主張 πj ∈ ΘLπ,π(j) は π′ = πϕ・θ = π と取った系。
Proposition 4.7(i) が xπj ∈ ΘL,×π,π(j) を出すのに使う。

★Lemma 4.6(θ による分点の同型 — 拡大体の f 非依存性) — 物理 p.8

Lemma 4.6. Let f, f′ ∈ OL[X] be as above with linear coefficients π, π′, respectively. If θ ∈ ΘL,×π,π′ (see Corollary 3.7(ii)), then for all m ≥ 1, it gives an isomorphism [θ] = [θ]f,f′ : µf,m → µf′,m of O-modules, and Lmf = Lmf′.

Proposition 4.7(K 上のガロア性と ρf,m の Weil 群への延長) — 物理 p.8

Proposition 4.7. Let m ≥ 1 and f ∈ OL[X] as above, with the linear coefficient π. (i) The Lmf is Galois over K, and the following map is bijective for any α ∈ µ×f,m: K×/(1 + pm) ∋ x mod 1 + pm ⟼ [xπj]f,f(j)(α) ∈ ∐j∈Z µ(j),×f,m (v(x) = −j). (ii) Let L = K. The ρf,m of Proposition 4.4(iii) extend to isomorphisms: ρf,m : W(Kmf/K) ≅⟶ K×/(1 + pm). (ϕj on K, α ↦ [xπj](α), ∀α ∈ µf,m) ⟼ x mod 1 + pm (v(x) = −j) Setting KLTf := ⋃m≥1 Kmf, we get ρf : W(KLTf/K) ≅⟶ K× by passing to the limit.
★Artin 写像の逆写像 ρ が構成される場所。 (i) は「Lmf は L 上だけでなく K 上ガロア」で、 §6 の Proposition 6.14 が Gal(Kmx/L) を語れる前提になる。 (ii) は L = K と置いたときに ρf,m が Weil 群 W(Kmf/K) 全体へ延び、 K×/(1+pm) と同型になること。極限で ρf : W(KLTf/K) ≅ K×。

★Definition 4.10(Km・KLT・Artin 写像 ArtK) — 物理 p.9

Definition 4.10. For any f ∈ OL[X] with L/K finite, set Km := KurLmf. Then Km/K is finitely ramified, and Galois by Proposition 4.7(i). By Lemma 2.2, the completion of Km is KLmf = Km and Km = Km ∩ Ksep, thus independent of f. Setting KLT := ⋃m≥1 Km = KLT ∩Ksep, we have W(KLT/K) ≅ W(KLT/K) by the remark after Definition 2.5. We call a finite extension of K a Lubin-Tate extension if it is contained in KLT. We call the inverse of ρ the Artin map of K and write ArtK : K× ≅⟶ W(KLT/K). We have v ∘ ArtK = v.

★測定係が「読めなかった」と報告していた 1 行を、PDF 目視で確定させた(2026-09-07、 物理 p.9 を pdftoppm -r 170 で画像化して全面目視)。

確定した本文(上の .verbatim がそれ): Km := KurLmf が定義であり、 Km = Km ∩ Ksep はそこから従う等式である (定義ではない)。「Km := Km ∩ Ksep と読むのではないか」という 推測は否——原典はそう書いていない。
★「with L/K finite」は §4.1 と矛盾しない。 測定係が矛盾と見たのは 「§4.1 は L を complete unramified extension と固定している」という点だったが、 Definition 2.4 が 「E/K が有限なら L = E = E」と明記しており、 有限不分岐拡大 Kn は complete unramified extension の一種である。 Definition 4.10 はその中で L/K が有限なものに制限しているだけ—— 制限する理由は明白で、Lmf を K 上代数的な体にしたいから (L = K のままだと Lmf ⊄ Ksep になり KurLmf が Ksep の部分体にならない)。
論理の流れ: (1) Km := KurLmf(f と L に依存しうる)→ (2) その完備化は KLmf = Kmf、 これは Corollary 4.9 で f に依らない → (3) Lemma 2.2(iii) (E ∩ Ksep = E)で Km = Km ∩ Ksep → (4) ゆえに Km も f に依らない。 ★Lemma 2.2(iii) が「完備側の一意性を代数側へ降ろす」役をしている ——Milne CFT の Lemma 3.12 と同じ役回り。
Artin 写像は ρ(Proposition 4.7(ii) の極限)の逆として定義され、 ArtK : K× ≅ W(KLT/K)、v ◦ ArtK = v。 §5 の Corollary 5.16 と §6 の Theorem 6.15 が消費するのはこの ArtK である。
