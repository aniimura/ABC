§3 見出し & §3.1 冒頭(A[[X]] と合成のモノイド) — 物理 p.4

3. Formal groups and Lubin-Tate groups 3.1. Formal groups. Let A be a ring, not the zero ring. In the formal power series ring of one variable A[[X]] := lim←m A[X]/(Xm) over A, the ideal (X) ⊂ A[[X]], consisting of all the elements with constant term equal to 0, is a monoid under the composition f ◦ g := f(g(X)) with X as the identity. For f ∈ (X), there exists an f−1 satisfying f ◦ f−1 = f−1 ◦ f = X if and only if the coefficient of X in f belongs to A×.
§3.1 は任意の環 A 上の形式群を扱う(局所体は §3.2 から)。 土台は「(X) ⊂ A[[X]](定数項 0 の冪級数)は合成についてモノイド」と 「可逆 ⇔ 1 次の係数が A×」の 2 つ。
★記法の脱落: 逆極限の lim← は pdftotext では lim / ←− / m の 3 トークンに割れて縦に並ぶ(data-txt="←−m")。 また合成記号 ∘(\circ)の出力は ◦(U+25E6, WHITE BULLET)であり、 本ファイルは出力側の U+25E6 をそのまま使う(§6 は data-txt で明示していたが、 §3·§4 は ◦ の出現が多すぎるので表示側も U+25E6 に揃えた。 ★§6 と流儀が違うことをここに記録する)。

Definition 3.1(形式群) — 物理 p.4

Definition 3.1. A formal group over A is a formal power series of two variables F(X, Y ) ∈ A[[X, Y ]] which satisfies the following: (i) F(X, Y ) ≡ X + Y (mod deg 2), (ii) F(F(X, Y ), Z) = F(X, F(Y, Z)), (iii) F(X, Y ) = F(Y, X).
形式群の定義。(i) は1 次までは加法、(ii) は結合律、(iii) は可換律。 逆元の存在は要求されておらず、後の段落で導かれる(次の項目 def-3-1-plus)。 原典は直後に「Precisely speaking, these are commutative formal groups of dimension 1」と注記する。
Lean 化の観点: mathlib に FormalGroup は無い。 PowerSeries(2 変数は MvPowerSeries)上に (i)(ii)(iii) を課す構造体が節点になる。

★地の文の暗黙の定義(逆元 iF と加法 +F) — 物理 p.4

Therefore we can solve F(X, Y ) = 0 with respect to Y and get a unique iF (X) ∈ A[[X]] satisfying F(X, iF (X)) = 0. If we define the addition +F on the ideal (X) ⊂ A[[X]] by f +F g := F(f(X), g(X)), then (X) becomes an abelian group with 0 as the identity and iF ◦ f as the inverse of f.
★見出し語を持たないが実質的な定義(README §3「地の文に埋め込まれた暗黙の定義」)。 2 つの対象が定義されている: (a) iF ∈ A[[X]](形式的な逆元。F(X, iF(X)) = 0 で一意に決まる)、 (b) +F((X) 上の加法 f +F g := F(f(X), g(X)))。 これで (X) がアーベル群になる。
★§4 が使うのはもっぱら (b)—— Proposition 4.4(i) の 「µf,m は +Ff と [·]f によって O-加群」が この +F のことである。 ここを切り出しておかないと Lean 側で作り直しになる。
原典は iF の存在を「Therefore we can solve …」の 1 語で畳んでいる ——実際には 形式的逆関数定理(Y の 1 次係数が可逆)を使う。

基本例(形式的加法群 Ŵa と乗法群 Ŵm) — 物理 p.4

Precisely speaking, these are commutative formal groups of dimension 1. The basic examples are the additive group Ga(X, Y ) := X +Y and the multiplicative group Gm(X, Y ) := X + Y + XY .
形式的加法群 Ga = X + Y と 形式的乗法群 Gm = X + Y + XY。 後者は Example 3.6 で K = Qp の Lubin-Tate 群として再登場し、 Example 4.2 で円分拡大を与える。
★記法の脱落 2 種: (a) G(\widehat{\mathbb G})は pdftotext に G としか出ない(帽子も黒板太字も落ちる)。 (b) ★行末のハイフネーション——原典 p.4 では “examples” が “ex-” / “amples” に折られており、pdftotext の出力は ex-amples(ハイフンが本文に残る)。 data-txt="ex-amples" で明示している—— これは装飾ではなく組版由来の差だが、README §3 の data-txt がそのまま使える。 本論文の物理 p.4–9 でこの折れ方が起きるのは3 箇所だけ(p.4 の ex-amples、 p.7 の O- module、p.8 の ar-gue)で、後 2 者は証明中なので本フォルダの逐語には現れない。

Definition 3.2(形式群の準同型) — 物理 p.4

Definition 3.2. Let F, G be formal groups over A. A power series f(X) ∈ (X) ⊂ A[[X]] is called a homomorphism from F to G if it satisfies f ◦ F = G ◦ f, i.e. f(F(X, Y )) = G(f(X), f(Y )),
準同型の定義。p.4 の最終行で切れており、続き (“and we write f : F → G. …”)は p.5 にある ——逐語照合は 1 ページ単位なので、続きは setup-3-1-hom(p.5)に分けた。
ここでの f ◦ F・G ◦ f は §3.1 冒頭で定義された 多変数への合成の略記(f ◦ F := f(F(X1, …, Xn))、 F ◦ f := F(f(X1), …, f(Xn)))である。

Definition 3.2 の続き + 暗黙の定義(HomA(F, G) と EndA(F)) — 物理 p.5

and we write f : F → G. Two homomorphisms compose via the composition of power series, with f(X) = X as the identity id : F → F. If f−1 exists, it defines f−1 : G → F and f ◦ f−1 = f−1 ◦ f = id. In this case f is called an isomorphism and we write f : F ≅⟶ G. The set HomA(F, G) of all homomorphisms from F to G is an abelian group under +G. Moreover, EndA(F) := HomA(F, F) is a (not necessarily commutative) ring with +F as the addition and ◦ as the multiplication.
★暗黙の定義が 2 つ: HomA(F, G)(+G によるアーベル群)と EndA(F)(+F を加法、◦ を乗法とする環)。 Corollary 3.7(i) の 「[·]f : O → EndOL(Ff) は単射環準同型」が この環構造を指す——形式 O-加群という言葉の中身はここにある。
★記法: 同型を表す ≅ つき矢印は pdftotext で ∼ / = / −→ の3 トークンに割れて縦に並ぶ。 check.mjs の正規化は隣接した ∼= しか ≅ に畳まないので、 本ファイルは data-txt="∼ ="(空白込み)+ data-txt="−→" と 2 つに分けて書いている。

§3.2 冒頭(局所体 K・完備不分岐拡大 L・Frobenius ϕ) — 物理 p.5

3.2. Lubin-Tate groups. We return to the notation of §2.2, i.e. K is a local field with the ring of integers O and its maximal ideal p, and O/p ≅ Fq where q is a power of p. Let L be a complete unramified extension of K (§2.2). As pL = pOL, we write mod p for mod pOL. Let ϕ be the arithmetic Frobenius, extended to a K-automorphism of L. For α ∈ L and i ∈ Z, we write αϕi := ϕi(α). For a power series F over OL, we define Fϕi by applying ϕi to all coefficients of F. If F is a formal group over OL, so is Fϕi.
§3.2 以降の固定された設定: K は局所体、L は K の完備不分岐拡大、 ϕ は算術 Frobenius を L へ延長したもの。 係数に ϕi を施す操作 F ↦ Fϕi がここで定義され、 これが Lubin-Tate 条件 f′ ◦ F = Fϕ ◦ f(Lemma 3.4)の 右辺に現れる——§3·§4 全体を通じて最も基本的な操作。
★記法: ϕ は原典が \varphi(U+03C6 の字形)だが、 pdftotext の出力は U+03D5(GREEK PHI SYMBOL)である。 §6 の φG(Herbrand 関数、\phi)が U+03C6 で出るのと 符号位置が逆になっている——この論文には U+03D5(Frobenius)と U+03C6(Herbrand 関数)の 2 つの phi が別対象として存在するので、 grep するときは取り違えないこと。

★Definition 3.3(ΘLπ,π′) — 物理 p.5

Definition 3.3. For uniformizers π, π′ of L, set ΘLπ,π′ := {θ ∈ OL | θϕ/θ = π′/π}. It is an additive group. If θ ∈ ΘLπ,π′ and θ′ ∈ ΘLπ′,π′′, then θθ′ ∈ ΘLπ,π′′. We have O ⊂ ΘLπ,π (actually we will see O = ΘLπ,π by Lemma 5.2(i)).
★Λ6 が「Dwork のねじれ元」と呼んでいる対象の原典側の名前。 2 つの素元 π, π′ に対し ΘLπ,π′ = {θ ∈ OL | θϕ/θ = π′/π}。
3 つの性質が同時に述べられている: (a) 加法群、(b) 合成則 Θπ,π′ · Θπ′,π″ ⊂ Θπ,π″ (π を頂点とする亜群の構造)、(c) O ⊂ ΘLπ,π (等号は Lemma 5.2(i) —— ϕn の固定体が Kn であること)。
★§4 での使われ方: 単元だけを取り出した ΘL,×π,π′ := ΘLπ,π′ ∩ OL× (Corollary 3.7(ii))が Lemma 4.6(= Λ6 #7)の仮定であり、 その非空性が Proposition 4.8(= 着地済みの Dwork 乗法版)である。
★記法: 2 重プライム π′′ は pdftotext では U+2032 が 2 つとして出る(U+2033 &Prime; ではない)。 ★ここで一度落とした——&Prime; と書くと check.mjs の実体表(ENTITIES)に Prime が無いため 実体が解決されず、逐語照合の投影に文字列 &Prime; がそのまま残って S4 が落ちる。 本ファイルは &prime;&prime;(2 つ)と書いて回避している。 ★教訓: .verbatim で使ってよい名前つき実体は check.mjs の ENTITIES にあるものだけ。 それ以外は数値実体(&#960; 等)で書くこと ——&pi; や &theta; も表に無い。

★Lemma 3.4(Lubin-Tate の一意存在補題。条件 (3.2.1) の定義を含む) — 物理 p.5

Lemma 3.4. Let π be a uniformizer of L, and let f ∈ OL[[X]] satisfy: (3.2.1) f(X) ≡ πX (mod deg 2), f(X) ≡ Xq (mod p). Let π′, f′ be another such pair. Assume that θ1, . . . , θt ∈ ΘLπ,π′. Then there is a unique F ∈ OL[[X1, . . . , Xt]] satisfying the following: F ≡ θ1X1 + · · · + θtXt (mod deg 2), f′ ◦ F = Fϕ ◦ f.
★§3 の技術的な心臓部。Lubin-Tate 条件 (3.2.1) (f ≡ πX (mod deg 2) かつ f ≡ Xq (mod p))を満たす 2 つの f, f′ と θ1, …, θt ∈ ΘLπ,π′ に対し、 1 次部分を指定すれば f′ ◦ F = Fϕ ◦ f を満たす F が一意に存在する。
証明は次数 m についての帰納法で、各次数で係数が一意に決まることを示す (α = −β − ∑i≥1(πm+1/π′)1+ϕ+…ϕi−1βϕi という無限和が出るので、Appendix I の収束が要る)。
★この 1 つの補題から §3 の残り全部が出る—— Proposition 3.5 の (i)(ii)(iii) はすべて 「Lemma 3.4 を t = 1, 2, 3 で使う」だけである。 Lean 化ではここが §3 で唯一の重い節点になる。

★Proposition 3.5(Lubin-Tate 群 Ff と [θ]f,f′) — 物理 p.5

Proposition 3.5. Let f, f′ ∈ OL[[X]] be as above, with linear coefficients π, π′ respectively. (i) There exists a unique formal group Ff over OL such that f ∈ HomOL(Ff, Fϕf). (We call Ff the Lubin-Tate group associated to f.) (ii) There is a unique map [·]f,f′ : ΘLπ,π′ → (X) ⊂ OL[[X]] such that: [θ]f,f′(X) ≡ θX (mod deg 2), f′ ◦ [θ]f,f′ = [θ]ϕf,f′ ◦ f. It satisfies [θ]f,f′ +Ff′ [θ′]f,f′ = [θ + θ′]f,f′, [θ′]f′,f′′ ◦ [θ]f,f′ = [θθ′]f,f′′. (iii) We have [θ]f,f′ ∈ HomOL(Ff, Ff′) for all θ ∈ ΘLπ,π′.
★Λ6 消費側が「Lubin-Tate 群の構成」と呼んでいる主張の原典。3 つの主張:
  • (i) 各 f に対し形式群 Ff が一意に存在し、f は Ff → Fϕf の準同型になる。
  • ★(ii) [·]f,f′ : ΘLπ,π′ → (X) が一意に存在し、 加法的([θ] +Ff′ [θ′] = [θ+θ′])かつ 合成が積([θ′] ◦ [θ] = [θθ′])。
  • (iii) [θ]f,f′ は形式群の準同型 Ff → Ff′。
証明はすべて Lemma 3.4 の一意性を t = 1, 2, 3 で当てるだけ—— 「2 つの式が同じ条件を満たすから等しい」という論法を 5 回繰り返す。
★§4 での消費先: (ii)(iii) が Lemma 4.6(= Λ6 #7)の 「[θ] は O-準同型」の根拠。 (i) が Proposition 4.4(i) の +Ff。

Example 3.6(Qp の場合は形式的乗法群) — 物理 p.6

Example 3.6. If K = Qp, π = p and f = (1 + X)p − 1, then Ff = Gm = X + Y + XY .
K = Qp・π = p・f = (1+X)p−1 のとき Lubin-Tate 群は形式的乗法群 Gm。 Example 4.2 で円分拡大が Lubin-Tate 拡大の特別な場合であることに繋がる。 Lean 化のとき最初に通すべき健全性検査がこれ。

★Corollary 3.7(形式 O-加群構造と ΘL,× の定義) — 物理 p.6

Corollary 3.7. (i) The map [·]f := [·]f,f : O ⟶ EndOL(Ff) is an injective ring homomorphism. (Hence (Ff, [·]f) is a formal O-module.) (ii) If θ ∈ ΘL,×π,π′ := ΘLπ,π′ ∩ O×L, then [θ]f,f′ is an isomorphism with the inverse [θ−1]f′,f.
★(ii) が ΘL,×π,π′ の定義そのもの ——Lemma 4.6(Λ6 #7)と Proposition 4.8(着地済み)が どちらもこの記号を仮定/結論に持つので、ここが両者の共通の入口である。 θ が単元なら [θ]f,f′ は同型で、逆は [θ−1]f′,f。
(i) は O → End(Ff) が単射環準同型であること ——これで (Ff, [·]f) が形式 O-加群になる。 ΘLπ,π ⊇ O(Definition 3.3)の 上で Proposition 3.5(ii) を読み直しただけ。
★記法: ⟶(\longrightarrow)は pdftotext に −→(U+2212 + U+2192)の 2 文字として出る。

Example 3.8(f 自身が [π]) — 物理 p.6

Example 3.8. We have π ∈ ΘLπ,πϕ, and [π]f,fϕ = f : Ff → Fϕf for f satisfying (3.2.1), by uniqueness. (Also note that Fϕf = Ffϕ and [θ]ϕf,f′ = [θϕ]fϕ,f′ϕ by uniquness.)

★原典の誤植をそのまま写している: 最後の語は “uniquness”(“uniqueness” の e が落ちている)。 逐語は原典に忠実にするので修正しない(README §5)。
