主定理(Theorem A、物理 p.1)

任意の局所体 K に対し、Artin 写像 ArtK : K× → Gal(Kab/K) が 2 条件((a) 素元 → Frobenius、(b) 有限アーベル拡大のノルム群 → 恒等)で一意に定まり、 WabK の上への同型になる。さらに有限分離拡大 K′/K に対して基底変換が可換。 逐語は section-1.html#thm-A。

本論文の構成は Theorem A = Corollary 5.16 + Theorem 6.15 と分割される—— §5 が「Kab を KLT(Lubin-Tate 拡大の合併)に置き換えた LCFT」を、 §6 が「KLT = Kab(局所 Kronecker-Weber)」を担当する。 §1 が自ら述べる新機軸は、基底変換(Theorem 5.15)を LKW より先に直接示す点にある。

記法の状況(papers.json: notationRisk = medium)

arXiv の LaTeX 版なので本文の抽出は良好だが、数式中の記号は落ちる。 目視で確認した脱落(すべて本フォルダの data-txt に反映済み):

  • ≠ → = — 斜線が消え、主張が反転して読める。 Cor 6.3・Lemma 6.5・Thm 6.11 の 3 箇所で発生。この論文で最も危険な脱落。
  • ⟨ ⟩(生成部分群)→ 出力なし。|⟨σ⟩| = pm が | σ | = pm としか出ず、元と生成群の区別が消える(Prop 5.4・5.10・5.14、Cor 5.12、Prop 6.6)。
  • ∑ ⋃ ⋂(大演算子)→ 出力なし。上下の添字だけが本文に落ちる。
  • 分数の横線 → 出力なし。1/|H| が 1 |H| になる(Lemma 6.8・Prop 6.9・Lemma 6.10)。
  • ≅ → ∼ と = の 2 トークンに割れる(-raw では行も割れる)。 check.mjs の正規化は隣接した ∼= しか畳まないので、 本フォルダは data-txt="∼ =" と空白込みで投影を書いている。
  • ▷(\rhd)→ ⊲(U+22B2)。字形と符号位置が食い違う(setup-6-2、Cor 6.13)。
  • ∘(\circ)→ ◦(U+25E6, WHITE BULLET)。同上(Lemma 6.10)。
  • ϕ(\phi)→ φ(U+03C6)。本フォルダは出力側の U+03C6 に合わせている。
  • 𝒪(script O)→ O、𝔥(fraktur p)→ p、 黒板太字 ℤ ℝ 𝔽 → Z R F、上線 σ̄ → σ。 いずれも README §1 の「基底文字だけが残る」通り。
