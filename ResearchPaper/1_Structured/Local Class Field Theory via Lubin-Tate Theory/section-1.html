§1 冒頭(前提と本論文の位置づけ) — 物理 p.1

We prove local class field theory via Lubin-Tate theory and the Hasse-Arf theorem. The only prerequisites are Galois theory (including cyclotomic extensions, finite fields and infinite extensions) and some basic commutative algebra summarized in Appendix I. We have tried to make the paper self-contained, to the extent of repeating proofs of standard results on local fields and avoiding topological arguments using compactness. Our argument is close to Iwasawa [9], but the main innovation here is to use the relative Lubin-Tate groups of de Shalit [5] to prove the base change property (Theorem 5.15) directly, without proving the local Kronecker-Weber theorem first.
★本プロジェクトがこの論文を選んだ理由がここに書いてある—— “self-contained” かつ “avoiding topological arguments using compactness”。 前提はガロア理論と Appendix I の可換環論だけであり、境界外入力がほぼ無い。 Lean 化にあたっては「compactness を避けている」ことが特に効く (Lemma 5.13 が有限集合の逆極限で押し切るのがその実例)。

Theorem A(局所類体論) — 物理 p.1

Theorem A (Local Class Field Theory). (i) For any local field K, there is a unique homomorphism ArtK : K× ⟶ Gal(Kab/K), characterized by the two properties: (a) If π is a uniformizer of K, then ArtK(π)|Kur = FrobK. (b) If K′/K is a finite abelian extension, then ArtK(NK′/K(K′×))|K′ = id. Moreover, ArtK is an isomorphism onto WabK := {σ | σ|Kur ∈ FrobZK} ⊂ Gal(Kab/K). (ii) If K′/K is finite separable, then ArtK′(x)|Kab = ArtK(NK′/K(x)) for all x ∈ K′×, and ArtK induces an isomorphism K×/NK′/K(K′×) ≅→ Gal((K′ ∩ Kab)/K).
本論文が到達する主張。§5 の Corollary 5.16 が Kab を KLT に置き換えた形をすでに与えているので、 残りは KLT = Kab——すなわち §6 の Theorem 6.15(局所 Kronecker-Weber)。
証明の分割: Theorem A = Corollary 5.16 + Theorem 6.15。 そして Theorem 6.15 = Hasse-Arf(Theorem 6.11)+ Lubin-Tate 側の計算 (Proposition 6.14)。
★記法: WabK と FrobℤK は pdftotext -raw では基底 → 上付き → 下付きの順に割れる (Wab/K、FrobZ/K)。黒板太字 ℤ は Z にしか出ない。
