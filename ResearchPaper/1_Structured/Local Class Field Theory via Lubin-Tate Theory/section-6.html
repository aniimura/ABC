§6.1 冒頭(分岐群の設定) — 物理 p.14

6.1. Ramification groups. Let K′/K be a finite totally ramified Galois extension of local fields, and set G := Gal(K′/K). For a uniformizer π of K′, we have OK′ = O[π] by Lemma 5.11. We write v := vK′ and q = |O/p| = |OK′/pK′|.
§6 全体を通じての約束: K′/K は有限・完全分岐・ガロアで、G := Gal(K′/K)。 π は K′ の素元、v := vK′(K′ の正規化付値、v(π) = 1)、q は剰余体の位数。 Lemma 5.11 がここで消費される——OK′ = O[π] という 単項生成が、以下すべての「σ を π での値だけで測る」議論の土台になる。

Definition 6.1(下付き番号付けの分岐群) — 物理 p.14

Definition 6.1. Let i(σ) := v(σ(π) − π), where we set i(id) = ∞. For n ≥ 0, define Gn := {σ ∈ G | i(σ) > n} = {σ ∈ G | σ(π)/π ∈ 1 + pnK′}. Then G = G0 as K′/K is totally ramified, and Gn = {id} for sufficiently large n. They are normal subgroups of G, independent of the choice of π, because Gn = {σ ∈ G | v(σ(a) − a) > n for all a ∈ OK′} is the kernel of the group homomorphism G ∋ σ ⟶ σ|OK′ mod pn+1K′ ∈ Aut(OK′/pn+1K′).
★Lean 側の消費先: lean/ABC3/Found/PGC/LowerRamificationGroup.lean の lowerRamificationGroup(.src の pdfPage は 着手時点で 13、同日 14 に修正済み——Definition 6.1 の本体は物理 p.14 にあり、 p.13 末にあるのは §6 の導入段落だけである。経緯は 目次の「Lean 側からの参照」を見よ)。
原典は 3 つの同値な定義を一息で並べている: (a) i(σ) > n、(b) σ(π)/π ∈ 1 + 𝔭n、 (c) 全ての a ∈ 𝒪K′ で v(σ(a) − a) > n。 (c) が「G → Aut(𝒪K′/𝔭n+1) の核」という記述を与え、そこから 正規部分群であることとπ の取り方に依らないことが同時に出る。
「独立性」「正規性」は原典では because の一語で畳まれている——(c) の形に書けば自明、という論法。 Lean 化ではこの (a)⇔(b)⇔(c) の 3 者同値そのものが節点になる。

Proposition 6.2(分岐群の商の埋め込み) — 物理 p.14

Proposition 6.2. For n ∈ Z≥0, we have the following injective group homomorphisms, independent of the choice of π (they show that G is supersoluble): θ0 : G0/G1 ∋ σ ⟶ σ(π)/π mod pK′ ∈ (OK′/pK′)× ≅ F×q, θn : Gn/Gn+1 ∋ σ ⟶ (σ(π)/π) − 1 mod pn+1K′ ∈ pnK′/pn+1K′ ≅ Fq (n ≥ 1).
分岐群のフィルトレーションの段差を測る 2 本の単射。G0/G1 ↪ 𝔽q× (位数 q−1 の巡回群)と Gn/Gn+1 ↪ 𝔽q+(初等 p-アーベル)。 ここから G1 は p 群、G0/G1 は p と素な巡回群が従い、 これが Corollary 6.3・Proposition 6.6・Theorem 6.11 の全ての土台になる。
★data-txt="∼ =" について: 原文の ≅ を pdftotext は ∼ と = の2 トークンに割って出す(-raw では行も割れる)。 check.mjs の正規化は隣接した ∼= のみを ≅ に畳むので、 空白を含む "∼ =" を投影として明示している。

Corollary 6.3 — 物理 p.14

Corollary 6.3. If G is abelian and Gn ≠ Gn+1, then e0 := |G0/G1| divides n.
Hasse-Arf(Theorem 6.11)の最後の段(G ≠ G1 の場合)で使われる整除性。
★記法の復元: 原文は Gn ≠ Gn+1 だが、≠ の 斜線はベクター描画で pdftotext に出ない——出力は = だけ。 これは README §1 の「装飾は基底文字だけが残る」と同型の脱落であり、 テキストだけを読むと主張が反転する(「Gn = Gn+1 なら」と読めてしまう)。 本ファイルでは ≠ の出現をすべて data-txt="=" で明示している。

Lemma 6.4 — 物理 p.14

Lemma 6.4. For σ ∈ G1, we have v(∑p−1i=0 σi(α)) > v(α) for all α ∈ K′×.
Sen の定理(Proposition 6.6)の (i) と (iii) の両方で使われる評価。 G1 の元 σ に対して「トレース類似物 ∑iσi(α) は α より真に高い付値を持つ」。 証明は (σ−1) の反復と ∑iXi = (X−1)p−1 in 𝔽p[X] の 2 行。
★記法: 大きな括弧 ( ) と総和記号 ∑ は pdftotext に一切出力されない(data-txt="")。README §3 の 「平文記法の限界」で挙がっている「消える記号」がこの論文にも現れる。

Lemma 6.5 — 物理 p.14

Lemma 6.5. Let σ ∈ G1. For each n ∈ Z, there exists α ∈ K′× such that v(α) = n and v(σ(α) − α) = n + i(σn). Moreover, any x ∈ K′× can be written as a sum x = ∑∞n=v(x) xn (see Appendix I) where each xn satisfies above two properties for n if xn ≠ 0.
「各付値 n ごとに、σ の動きが n + i(σn) ちょうどになる元 α を作れる」+ 「任意の元をそういう元の(Appendix I の意味で収束する)和に分解できる」。 Proposition 6.6(iii) の背理法で、この分解に Claim(相異なる付値)を当てて矛盾を出す。
★xn ≠ 0 の ≠ も = にしか出ない(Corollary 6.3 と同じ脱落)。

Proposition 6.6(Sen [14]) — 物理 p.15

Proposition 6.6 (Sen [14]). Let σ ∈ G1, and |⟨σ⟩| = pm for m ≥ 1 (by Proposition 6.2). Let Hn := Gn ∩ ⟨σ⟩ for n ≥ 1 and ij := i(σpj) for j ≥ 0 (and ij := ∞ for j ≥ m). Then: (i) ij−1 < ij if j ≤ m. Also, Hn = ⟨σpj⟩ if and only if ij−1 ≤ n < ij. (ii) i(σa) = ivp(a) for a ≥ 1, where vp := vQp. (iii) ij−1 ≡ ij (mod pj), where ∞ is understood to be congruent to any integer.
Sen の定理。巡回 p 群 ⟨σ⟩ に対して、分岐の跳び位置 ij = i(σpj) が (i) 狭義増加・(ii) i(σa) は vp(a) だけで決まる・ (iii) ij−1 ≡ ij (mod pj) を満たす。 (iii) が Hasse-Arf の整数性の源。原典は (iii) の証明に 1 ページ弱を割いており、この論文で最も重い一段。
★記法: 生成部分群の角括弧 ⟨ ⟩ は pdftotext に出ない (| σ | = pm としか出ない)。README §1 の [EtTh] の下線と同じく、 テキストだけでは「σ そのもの」と「σ の生成する群」が区別できない。

Corollary 6.7 — 物理 p.15

Corollary 6.7. Assume G ≅ Z/pmZ. Then there exist n0, n1, . . . , nm−1 ∈ Z≥1 such that, for 1 ≤ j ≤ m − 1, we have |Gn| = pm−j if and only if ∑j−1i=0 nipi < n ≤ ∑ji=0 nipi.
Proposition 6.6 を巡回 p 群の場合に読み替えた形——跳び位置が n0, n0+n1p, … という p 進展開の形をとる。 Theorem 6.11 の帰納法の底(j = 1、G ≅ ℤ/pmℤ)でそのまま使われる。

§6.2 冒頭(商への降下の設定) — 物理 p.15

6.2. The Hasse-Arf theorem. Let G = Gal(K′/K) with K′/K totally ramified as before, and let G ▷ H with G/H = Gal(K′′/K). For σ ∈ G, let σ = σH ∈ G/H be its image.
Lemma 6.8・Proposition 6.9(Herbrand)・Lemma 6.10 が共有する設定: 正規部分群 H ◂ G と中間体 K″ = K′H、および剰余類 σ = σH。
★記法: 原典の記号は ▷(\rhd、白三角)だが pdftotext は ⊲(U+22B2, NORMAL SUBGROUP OF)を出す—— 字形と符号位置が食い違っている。表示側は PDF の字形を、data-txt は実出力を持つ。 また上線付き σ は σ としか出ない (README §1 の K̄ → K と同じ脱落)。

Lemma 6.8 — 物理 p.15

Lemma 6.8. For all σ ∈ G, we have i(σ) = 1/|H| ∑τ∈H i(στ).
商 G/H の側で測った i(σ) が、剰余類 σH 上の i の平均である、という等式。 Herbrand(Proposition 6.9)の証明はこの 1 行に帰着する。 証明は K′′ の素元の最小多項式に σ を作用させて a | b と b | a を両方示す 2 段。
★記法: 分数 1/|H| の横線は pdftotext に出ず、分子・分母が 1 |H| と並ぶだけになる(data-txt="1|H|")。総和記号 ∑ も出ない。

Proposition 6.9(Herbrand) — 物理 p.16

Proposition 6.9 (Herbrand). Define φH(n) := −1+1/|H| ∑τ∈H min{i(τ), n+1} for n ∈ R≥0. Also, for n ∈ R≥0, define Gn := {σ ∈ G | i(σ) ≥ n + 1}, i.e. Gn = Gi if i ∈ Z≥0 and n ∈ (i − 1, i]. Then GnH/H = (G/H)φH(n) for all n ∈ R≥0.
★Herbrand の定理。Herbrand 関数 φH を「i の切り詰め平均」として直に定義し、 分岐群は商へ整合的に降りる(GnH/H = (G/H)φH(n))ことを示す。 下付き番号付けを実数に延長した Gn := {σ | i(σ) ≥ n+1} がここで導入される (整数 n では Definition 6.1 の Gn と一致する)。
Lean 化の観点: Definition 6.1 の実数への延長と φH の定義が、 Herbrand の主張そのものより先に必要な節点になる。
★φ は原典の字形が ϕ(\phi)だが、pdftotext の出力は U+03C6(φ)。本ファイルは出力に合わせて U+03C6 を使う—— 字形の差は同定に効かないと判断した(README §5「同定に関わらない装飾は落としてよい」)。

Lemma 6.10 — 物理 p.16

Lemma 6.10. Let φG(n) := −1 + 1/|G| ∑τ∈G min{i(τ), n + 1} for n ∈ R≥0. Then: (i) φG(0) = 0, φG(n) = 1/|G| ∑ni=1 |Gi| for n ∈ Z≥1. (ii) φG = φG/H ∘ φH on R≥0.
Herbrand 関数の 2 つの基本性質: (i) 整数点での閉じた形 (φG(n) = (1/|G|)∑i=1n|Gi|)と (ii) 合成則。 (ii) の証明は「φ は連続な区分線形で φ(0)=0 だから微分だけ比べればよい」という 3 行—— 区分線形関数の一致判定を Lean で立てるとここが独立の節点になる。
★記法: 合成記号は原典が ∘(\circ)、pdftotext の出力は ◦(U+25E6, WHITE BULLET)。▷/⊲ と同型の符号位置ずれ。

Theorem 6.11(Hasse-Arf) — 物理 p.16

Theorem 6.11 (Hasse-Arf). If G is abelian, n ∈ Z≥0 and Gn ≠ Gn+1, then φG(n) ∈ Z≥0.
★Hasse-Arf の定理——本論文の §6 が向かう頂点。 「アーベル拡大では、下付き番号付けの跳びの位置は Herbrand 関数で送っても整数のまま」。 これが「上付き番号付け Gm(Definition 6.12)が整数点で跳ぶ」を保証し、 Corollary 6.13(iii) の指数評価を通じて局所 Kronecker-Weber(Theorem 6.15)に効く。
証明の骨格: (1) G = G1(p 群)のとき——巡回成分数 j による帰納法。 底(j=1)は Corollary 6.7、帰納段は Proposition 6.9 + Lemma 6.10(ii)。 (2) G ≠ G1 のとき——H = G1 をとり、Corollary 6.3 の整除性で e0 | φH(n) を出す。
★Gn ≠ Gn+1 の ≠ は pdftotext に出ない(Corollary 6.3 と同じ)。

Definition 6.12(上付き番号付け) — 物理 p.17

Definition 6.12. For m ∈ R≥0, set Gm := Gφ−1G(m) (the upper numbering).
上付き番号付けの定義。Herbrand 関数の逆で下付きを付け替えるだけ—— φG は狭義単調増加な区分線形全単射 ℝ≥0 → ℝ≥0 なので逆が存在する。 その全単射性は原典では明示されていない(Lemma 6.10 の形から読み取れ、という扱い)—— Lean 化では φG の狭義単調性・連続性・非有界性が独立の節点になる。
pGC §2(Definition 2.3、上付き番号付けの高次分岐群)と同じ対象を定義しており、 Λ7 はこちらを実装本体にして pGC 側をその上に載せる予定。

Corollary 6.13 — 物理 p.17

Corollary 6.13. (i) If G ▷ H, then GmH/H = (G/H)m for all m ∈ R≥0. (ii) Let K′/K and K′′/K be two Galois extensions with K′K′′/K totally ramified. If Gal(K′/K)m = Gal(K′′/K)m = {id} for m ∈ R≥0, then Gal(K′K′′/K)m = {id}. (iii) Let G be abelian. Then |G/Gm| divides (q − 1)qm−1 for m ∈ Z≥0.
上付き番号付けの 3 つの帰結。(i) 商と可換(下付きに対する Herbrand の言い換え)。 (ii) 合成体でも上付き分岐が消える。(iii) Hasse-Arf を消費する唯一の場所—— 「跳びは整数点でしか起きない」から |G/Gm| が (q−1)qm−1 を割る。 Theorem 6.15 の証明は (ii) と (iii) をこの順に使う。

Proposition 6.14 — 物理 p.17

Proposition 6.14. Let x ∈ K× with v(x) = n > 0. Let L = Kn and Kmx as in Definition 5.3. Then we have Gal(Kmx/L)m = {id} for all m ≥ 1 (see Definition 6.12).
Lubin-Tate 拡大 Kmx/L の上付き分岐が m で消えるという計算。 証明は Proposition 4.4 で i(σ) = v(σ(α)−α) を Lubin-Tate 加群の割り算に翻訳し、 |Gn| = qm−i(qi−1−1 < n ≤ qi−1)を出してから Lemma 6.10(i) で φG(qm−1) = m を計算する。 §4 の Lubin-Tate 側の入力(Proposition 4.3・4.4)が全部効くのがこの一段。

Theorem 6.15(局所 Kronecker-Weber) — 物理 p.17

Theorem 6.15. (Local Kronecker-Weber theorem) Every finite abelian extension of a local field K is a Lubin-Tate extension, i.e. KLT = Kab.
§6 の到達点であり、Theorem A(§1)の残り半分。Corollary 5.16 が 「KLT の範囲での LCFT」を既に与えているので、 KLT = Kab が示せれば Theorem A が閉じる。
証明: σ の固定体 Eσ をとり、Kab = KurEσ を見てから Eσ ⊂ Kramx に帰着。後者は Proposition 6.14 + Corollary 6.13(ii)(iii) で次数を押さえて出す。
