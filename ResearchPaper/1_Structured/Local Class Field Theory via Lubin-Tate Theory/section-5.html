Definition 5.3(相対 Lubin-Tate 拡大 Kmx) — 物理 p.10

Definition 5.3. Let x ∈ K× with v(x) = n > 0. Take a uniformizer π of L = Kn with NL/K(π) = x by Lemma 5.2(ii), and a monic f ∈ OL[X] satisfying (3.2.1) for π. Then for m ≥ 1, the fields Lmf depend only on x by Proposition 5.1 and Lemma 4.6, so we denote them by Kmx := Lmf, and set Kramx := ⋃m≥1 Kmx, which are totally ramified over L.
de Shalit の相対 Lubin-Tate 拡大。v(x) = n > 0 なる x ごとに、 不分岐拡大 L = Kn 上の形式群から Kmx の塔を作り、 その合併 Kramx を得る。これが「K 上完全分岐」な部分をすべて供給する (KLT = KurKramx、Proposition 5.4)。
★記法: 大合併 ⋃ は pdftotext に一切出力されない (README §3 の「消える記号」)。data-txt="" で明示している。

Proposition 5.4(Artin 写像の特徴づけ) — 物理 p.10

Proposition 5.4. For x ∈ K× with v(x) = n > 0, the element σ := ArtK(x) ∈ W(KLT/K) is characterized by v(σ) = v(x) and σ|Kramx = id. For all m ≥ 1, the Artin map induces the isomorphism K×/((1 + pm) × ⟨x⟩) ≅→ Gal(Kmx/K).
ArtK(x) は「不分岐側で Frobenius の v(x) 乗、Kramx 上で恒等」という 2 条件で一意に決まる。Theorem 6.15(LKW)の証明でも Corollary 5.12・Proposition 5.14 経由でも、 この特徴づけがそのまま使われる。
★記法: 大きな括弧 ( ) と生成部分群の角括弧 ⟨ ⟩ は出力されない。 また ≅ の上に乗った矢印は ∼ / = / −→ の 3 トークンに割れるので、data-txt="∼ = −→" と空白込みで明示している (隣接した ∼= は check.mjs の正規化が ≅ に畳んでしまうため)。

Definition 5.9(ノルム群) — 物理 p.11

Definition 5.9. For a finite separable extension K′/K, we denote the image NK′/K(K′×) of the norm map NK′/K : K′× → K× by N(K′/K). For any separable extension E/K, define N(E/K) := ⋂K′ N(K′/K) where K′ runs through all the finite extensions in E.
ノルム群 N(K′/K) の定義と、無限次拡大への延長(有限部分拡大のノルム群の共通部分)。 無限次への延長は Corollary 5.12(N(E/K) = ⟨x⟩)と Proposition 5.14 で使われる。
★記法: 大共通部分 ⋂ は出力されない。

Proposition 5.10 — 物理 p.11

Proposition 5.10. N(Kmx/K) = (1 + pm) × ⟨x⟩ for all m ≥ 1.

Lemma 5.11(完全分岐なら整数環は素元で単項生成) — 物理 p.12

Lemma 5.11. If L′/L is totally ramified and α is a uniformizer of L′, then OL′ = OL[α].
★Lean 側の消費先: lean/ABC3/Found/PGC/LowerRamificationGroup.lean の exists_uniformizer_adjoin_eq(.src は paper := "Yoshida08", pdfPage := 12, item := "Lemma 5.11", sectionId := "lemma-5-11")。

Corollary 5.12 — 物理 p.12

Corollary 5.12. If E/L is totally ramified and E contains Kramx, then N(E/K) = ⟨x⟩.
Proposition 5.10 を m → ∞ にした形。⋂m≥1(1 + 𝔭m) = {1} で 上から押さえ、Lemma 5.13 で下から(付値 [L:K] の元の存在)押さえる。

Lemma 5.13 — 物理 p.12

Lemma 5.13. Let P = PL := v−1L(1) be the set of all uniformizers of a local field L, and E/L a totally ramified extension. Then N(E/L)P := N(E/L) ∩ P is non-empty.
「完全分岐拡大のノルム群は素元を含む」。証明は有限段での Im Nm の射影極限が空でないこと (有限集合の逆極限は空でない)に帰着する——原典が「avoiding topological arguments using compactness」(§1)と宣言している通り、コンパクト性ではなく有限性で押している。
Lean 化では「有限集合の逆系の極限が空でない」が独立の節点になる (mathlib の nonempty_sections_of_finite_inverse_system が該当する見込み。未確認)。

§5.3 見出し — 物理 p.12

5.3. Base change and LCFT for Lubin-Tate extensions.
ここから Theorem 5.15(基底変換)へ向かう。§1 が「本論文の主たる新機軸」と述べているのは この基底変換を LKW より先に、直接示す点である。

Proposition 5.14 — 物理 p.12

Proposition 5.14. For σ ∈ W(Ksep/K) with v(σ) > 0, let Eσ ⊂ Ksep be its fixed field. Then N(Eσ/K) = ⟨Art−1(σ|KLT)⟩.
Weil 群の元 σ の固定体のノルム群が、Art−1(σ|KLT) の生成する群になる。 Theorem 5.15 の証明の唯一の道具。証明は 2 行——Proposition 5.4 で Kramx ⊂ Eσ を見て Corollary 5.12 を当てるだけ。

Theorem 5.15(基底変換) — 物理 p.12(可換図式は p.12 下部、証明は p.13)

Theorem 5.15. (Base change) For a finite separable K′/K, we have KLT ⊂ K′LT and the following commutes, i.e. for all x′ ∈ K′× we have ArtK′(x′)|KLT = ArtK(NK′/K(x′)).
★本論文の主定理級の一段——§1 が「de Shalit の相対 Lubin-Tate 群を使い、 局所 Kronecker-Weber を先に示さずに直接証明する」と宣言している対象。 証明は Proposition 5.14 の等式を NK′/K で押し出すだけで、 x ∈ 𝔭K′ ∩ K′× が K′× を生成することで一般化する。
逐語には可換図式そのものは含めていない——図式は「i.e.」以下の等式と同内容であり、 pdftotext は矢印とラベルを本文と分離して吐くため逐語照合に載せる意味が薄い(README §5)。

Corollary 5.16(LKW を除いた LCFT) — 物理 p.13

Corollary 5.16. (LCFT minus Local Kronecker-Weber) (i) There is a unique homomorphism ArtK : K× → Gal(KLT/K) satisfying: (a) if π is a uniformizer of K, then ArtK(π)|Kur = FrobK, and (b) if K′/K is a Lubin-Tate extension, then ArtK(N(K′/K))|K′ = id. Moreover, the ArtK is an isomorphism onto W(KLT/K) ⊂ Gal(KLT/K). (ii) If K′/K is finite separable, then KLT ⊂ K′LT, and ArtK′(x)|KLT = ArtK(NK′/K(x)) for all x ∈ K′×. The ArtK induces K×/N(K′/K) ≅→ Gal((K′ ∩ KLT)/K).
Theorem A の Kab をすべて KLT に置き換えた形。 §5 の到達点であり、残る差は KLT = Kab の一点だけ—— それを埋めるのが §6 の Theorem 6.15(局所 Kronecker-Weber)である。
本文はこの直後に、Corollary 5.16 から「easily」出るとして 4 件 ((i) 指数評価と等号条件 / (ii) ノルム群の包含と拡大の包含 / (iii) 合成体と共通部分 / (iv) 存在定理)を 証明なしで並べている——省略の合図 4 件。本ファイルは構造単位として切り出していない。
