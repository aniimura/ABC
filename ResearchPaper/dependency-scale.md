# 依存の規模——同一論文内グラフの実測(2026-08-15)

`check.mjs` の依存グラフは `.needs` の `otherPaper`(**論文をまたぐ辺**)だけを見ている。
しかし論文をまたぐ辺は**浅い**ことが分かったので、規模の本体は**同一論文内**にある。
それを `.txt` から機械的に測ったのがこの文書である。

再現: `node tools/intra-graph.mjs "<論文>.txt" "<根の項目>"`

## ★この数字の限界(先に書く)

1. **`pdftotext` 経由であり目視していない。** 事実2により項目名が壊れている可能性がある。
   **逐語には使えない。規模の当たりを付けるためだけのもの。**
2. **下界である。** 記号でしか参照されない依存(特定の prime-strip など)は
   番号付き項目として現れないので数えられない。
3. **根の選び方に依存する。** 下表は Corollary 3.12 から辿れる範囲であって IUT 全体ではない。
4. **`[SemiAnbd] Definition 3.1` の 1 件と `[IUTchI] Definition 3.1` の 4 件は
   抽出の失敗を疑うべき値である。** 他が 45〜83 なのに対して極端に低い。
   原因は未特定。**この2行は信用しない。**

## ★論文をまたぐ辺は浅い(別の測定)

未展開の葉6件それぞれの**1ページ目**から `[Ref] Item` を抽出した結果、
**2周目には他論文への辺が1本も無かった**:

```
Cor 3.12 → {IUTchI, IUTchII, IUTchIII, AbsTopIII} → {FrdI} → (他論文なし)
```

★**各項目の1ページ目だけの測定である。** 項目が複数ページにまたがる場合、
2ページ目以降に他論文への参照がある可能性がある。**外挿しないこと。**

## 言えること

- **規模を決めているのは論文の本数ではなく、同一論文内の依存の密度**である。
- **[FrdI] の密度が突出**(平均出次数 4.1、辺 184 本、到達 45/83)。
  Frobenioid が「中層の再開発1本ぶん」と見積もられたことと整合する。
- **[AbsTopIII] の深さが 7** で最も深い。log-shell の定義がここにあることと整合。
- Corollary 3.12 という**1つの系**から、5論文にまたがって **~255 項目**が要る。
  これが `.needs` として書き出されるべき**下界**である。
  現在 `.needs` に書き出せているのは **35 件**(2026-08-15 時点のゲート出力)。

## ★器具に対する含意

`ProofObligation.derivation` は現在 `(what : String) (page : Nat)` で
**指す先を持たない**(自由文字列)ので辺にならない。上の測定が正しければ、
**規模の本体である同一論文内の辺を、我々の器具は1本も数えていない**。
`derivation` に `item` を持たせるか、新しい構成子を足すかの検討余地がある。
ただし G7 の基準(1件で制度を作らない/出力が定数の検査は検査ではない)を当てること。
